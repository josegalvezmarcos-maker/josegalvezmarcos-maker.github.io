# Operaciones a pie de campo

Free warehouse-operations workspace and personal site by José Antonio Gálvez Marcos.
Live at https://josegalvezmarcos-maker.github.io/

All data stays in the visitor's browser. See `AGENTS.md` for structure and conventions.

```bash
npm install
npm run dev
npm test
npm run build   # static output in dist/client
```

Pushing to `main` deploys to GitHub Pages.
